# Geoportal - Teste

Este repositório contém um **geoportal em fase de teste**, desenvolvido para explorar o uso de mapas interativos com dados públicos.

## 📌 Conteúdo
- **Bens tombados estaduais de Minas Gerais**  
  Camada com informações sobre os bens culturais protegidos pelo Estado.
- **Limites municipais**  
  Camada geográfica mostrando os limites administrativos dos municípios mineiros.

## 🚀 Objetivo
Disponibilizar uma página online para experimentação e avaliação, permitindo que outras pessoas testem a visualização dos dados.
